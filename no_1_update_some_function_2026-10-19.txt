  to check changes with npm run typecheck, npm run lint and npm run build. It
  also covers:

  - Setup: the npm scripts, and the two environment variables the app needs,
    VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY. The app fails on startup if
    either is missing.
  - Routing and language: every route is declared twice, once for English and
    once under /zh-tw for Chinese. A new page has to be added to both. It also
    explains how the app picks the language and how to build links that keep the
    current one.

    English columns (eng_*, *_en). Pages show English when it exists and fall
    back to Chinese.
  - Supabase: the tables and the image storage bucket. Admin access is decided
    by email: an account is an admin if its email is in the admin_emails list in
    roberthut_site_settings. Both the database rules and the /admin pages check
    that list.
  - Edge functions: two are called directly by the site (exchange rates and link
    preview images). The other three are an API for n8n that's protected by the
    x-n8n-api-key header.
  - Other notes: the SQL files and guide for moving to a new Supabase project,
    how to add a tool to the Tools page, and the Bolt instruction to use only
    Tailwind and lucide-react icons.
