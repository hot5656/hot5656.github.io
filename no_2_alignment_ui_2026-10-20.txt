● 為什麼分享單篇文章時預覽不對

  原因：這個網站是 SPA，但 LinkedIn 和 Facebook 的爬蟲不會執行 JavaScript。

  1. vercel.json 把所有路徑（包括 /post/:slug）都導向同一份 index.html。
  2. index.html 裡的 OG 標籤是寫死的：og:title 是「Robert Hut」，og:url
     是首頁，og:image 是網站 banner，也沒有 og:description。
  3. 文章內容要等 React 在瀏覽器執行後才去 Supabase 讀取。爬蟲只看第一次收到的
     HTML，所以只看得到上面那組預設值。
  4. 另外，PostDetailPage 也完全沒有設定 title 或 meta。不過就算在前端用
     react-helmet 之類的方式補上，爬蟲還是看不到，因為它們同樣不執行 JS。

  解法：讓 Vercel 在伺服器端回傳 /post/:slug 時，就把這篇文章的 OG 標籤放進 HTML
  裡。

  - 新增一個 Vercel Function，例如 api/post-og.ts，並在 vercel.json 把
    /post/:slug 和 /zh-tw/post/:slug 改導到這個函式。
  - 函式用 slug 向 Supabase 查詢文章（只查 published = true 的），然後把
    index.html 裡的標籤換成文章的資料：
    - og:title 和 <title>：文章標題（英文路徑用 eng_title，沒有的話用 title）
    - og:description：excerpt 或 eng_excerpt
    - og:image：cover_image_url，沒有封面圖就用原本的 banner
    - og:url：這篇文章的完整網址
    - og:type：article
  - 一般使用者拿到的還是同一個 SPA，畫面不會有任何變化，只是 HTML 開頭的 meta
    換成了這篇文章的資料。
  - 部署後，用 Facebook Sharing Debugger
    (https://developers.facebook.com/tools/debug/) 和 LinkedIn Post Inspector
    (https://www.linkedin.com/post-inspector/)
    重新抓取網址，舊的預覽快取才會更新。
